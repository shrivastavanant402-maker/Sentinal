# Update PROGRESS.md

Before you finish your task (i.e., before your final response), you **must** update `PROGRESS.md` at the workspace root (`d:\antigravity_workspace\Sentinal\PROGRESS.md`).

## What to update

| Section | When to add an entry |
|---|---|
| **Done** | Any task, feature, or fix you fully completed. |
| **In Progress** | Work you started but did not finish. |
| **Next** | Planned work that should happen after yours. |
| **Known Bugs** | Any bugs, regressions, or failing tests you noticed. |

## Format

- Use a bullet (`- `) per entry.
- Keep entries short (one line). Include the file/component name when relevant.
- Add a date stamp in `YYYY-MM-DD` format at the end of each entry.
- Move items between sections as appropriate (e.g., "In Progress" → "Done").
- Do **not** remove entries added by other agents; only append or move them.
